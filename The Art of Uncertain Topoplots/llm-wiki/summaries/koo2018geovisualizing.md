# Geovisualizing Attribute Uncertainty of Interval and Ratio Variables: A Framework and an Implementation for Vector Data

**Citation:** Koo, Hyeongmo and Chun, Yongwan and Griffith, Daniel A. (2018)  
**Topics:** `geospatial visualization`, `uncertainty visualization`, `software tools`  
**Drill down:** [paper index](../index/koo2018geovisualizing.md) · [full extracted text](../raw/koo2018geovisualizing.md)

## Why this paper matters

Proposes a framework for showing attribute uncertainty in vector GIS data by extending bivariate mapping. An ArcGIS extension implements overlaid symbols on choropleths, color properties on proportional symbols, and composite proportional symbols.

## Key findings

- The design chooses uncertainty encodings according to whether the mapped attribute uses choropleth or proportional-symbol representation.
- The implementation provides three concrete tools inside a standard GIS environment.

## Scope and cautions

- The paper emphasizes framework and implementation rather than a large controlled user evaluation.
