# diegr: Dynamic and Interactive EEG Graphics

**Citation:** Geršlová, Zdeňka (2026)  
**Topics:** `software tools`, `neuroscience and EEG`  
**Drill down:** [paper index](../index/gerslova2026diegr.md) · [full extracted text](../raw/gerslova2026diegr.md)

## Why this paper matters

The CRAN reference manual for the diegr R package. It documents dynamic and interactive high-density EEG graphics, data manipulation, averaging, confidence intervals, scalp and topographic plots, and animations; it is API documentation, not an empirical paper.

## Key findings

- The package supports exploratory and communicative analysis of spatiotemporal high-density EEG signals.
- Its documented workflows include pointwise confidence intervals, jackknife averages, topographic plots, and 3D scalp representations.

## Scope and cautions

- Package documentation dated August 2026; verify behavior against the installed package version.
