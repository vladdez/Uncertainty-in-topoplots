Task 2

Explanation of the task 2

Task 2 examined whether participants could combine information about estimated voltage and its uncertainty to locate a relevant spatial region. On each trial, participants saw one EEG topoplot and were asked to select the scalp region with the highest signal-to-noise ratio (SNR), defined as the absolute average-referenced voltage divided by its standard error. They responded using a separate scalp layout divided into 64 selectable regions.

The task included three characteristic ERP patterns: MMN, P3, and N170. Each was shown using each of the seven visualization types. This produced 21 trials per participant, each on a separate page. Trial order was randomized separately for every participant.

Response scoring and trial reconstruction

  • For each participan we reconstructed presentation order. Each participant went through 21 randomly shuffled pages.

  • For each trial, survey recorded the visualization, ERP stimulus shown and one region selected by participant. There were 64 regions on selectable grid.

  • The selected region was matched to the corresponding stimulus and its stored region score in regions.txt.

  • The region score represents |Voltage|/SE at that region. This calcaulation is actually more complicated.

NoteHow the 0–1 region score was calculated

For each stimulus, the scoring pipeline performed the following steps:

  1. It loaded one average-referenced ERP case using the task, subject, time point, and condition recorded in task_configs_30_balanced. The fixed combinations were:

    ERP pattern Time point (index) Condition
    MMN 96 3
    N170 105 2
    P3 129 1

  2. It average-referenced the voltage across the \(N\) channels:

    \[ V_i^{AR} = V_i - \frac{1}{N}\sum_j V_j. \]

  3. It calculated a polarity-independent, t-like signal-to-noise value at each channel:

    \[ T_i = \frac{|V_i^{AR}|}{SE_i}. \]

  4. It interpolated the channel-level \(T_i\) values into a continuous topoplot grid. Only finite interpolated cells inside the visible head mask were retained.

  5. It fitted the saved 64-region polygon template to the topoplot domain. For each region \(k\), it averaged all retained grid cells that were inside both the polygon and the head mask:

    \[ R_k = \operatorname{mean}\{T(x,y):(x,y)\in\text{region}_k\}. \]

  6. It min–max normalized the 64 raw region scores separately within each stimulus:

    \[ S_k = \frac{R_k - \min_j R_j}{\max_j R_j - \min_j R_j}. \]

    The weakest region therefore receives 0, the strongest receives 1, and other regions are positioned proportionally between them. Scores are rounded to two decimal places.

Descriptive detection scores

  • The analysis contains 2,394 responses: 114 participants x 21 trials. Each visualization type therefore has 342 responses: 114 participants x 3 ERP patterns.

  • No reconstructed responses were excluded for missing model variables. All 2,394 records contained participant, stimulus, visualization type, pattern, position, and score.

  • Visualization type was treated as a categorical variable, with Basic topoplot as the reference condition. ERP pattern and stimulus were retained for the extended model.

  • Presentation position was represented by position_c = position - 11. Thus, position_c = 0 represents position 11, negative values represent earlier trials, and positive values represent later trials.

Detection-score analysis

  • The primary analysis uses the extended model:

    score ~ vistype + pattern + position_c + (1 | ID) + (1 | stimulus)

  • The outcome contains exact 0 and 1 values as well as intermediate scores. An ordered-beta model retains this graded information while supporting the complete closed interval from 0 to 1. A binary logistic model would instead treat every score below 1 as equally incorrect.

  • Every participant completed 21 trials, so responses from the same participant are related. Adding (1 | ID) gives each participant their own baseline detection performance while estimating common visualization, pattern, and presentation-position effects.

  • Some stimuli may be intrinsically easier to interpret than others. Adding (1 | stimulus) gives each stimulus its own baseline score, so visualization comparisons are not attributed to stimulus difficulty alone.

  • ERP pattern and centered presentation position adjust the visualization comparisons for the displayed pattern and for linear change as participants progressed through the task.

  • The simpler base model is shown first as a reference. It contains visualization type and a participant random intercept but does not adjust for pattern, presentation position, or differences among stimuli.

NoteWhy correlated participant-specific visualization slopes were not retained

We tested whether the effect of visualization type differed between participants by adding correlated participant-specific visualization effects: (1 + vistype | ID). The model could not estimate this full structure reliably:

  • It ended with convergence code 1, a non-positive-definite Hessian, and singular convergence.

  • The structure requires seven participant-level random coefficients and 28 variance–covariance parameters.

  • Each participant provided only three detection scores for each visualization type, which did not contain enough information to estimate all those parameters reliably.

We also tested simpler participant-specific structures:

  • A participant-specific position slope converged, but its estimated standard deviation was only 0.006.

  • A diagonal visualization structure, diag(0 + vistype | ID), converged with a positive-definite Hessian. It estimates separate participant-specific visualization variances without estimating their correlations.

We therefore retained participant and stimulus random intercepts in the primary model. This does not show that visualization effects are identical for every participant. It means that these data cannot reliably estimate the full correlated structure. The diagonal model remains available as a sensitivity analysis.

Completion-time analysis

  • Completion time was reconstructed from the 21 page-timing variables and linked to each trial by participant and presentation position.

  • Only non-missing positive times with an identified visualization type were retained. The descriptive table removes extreme times separately within each visualization type using the project’s IQR rule; the mixed model retains all positive times.

  • The model analyzes log completion time because trial times are positive and typically right-skewed:

    log(time_sec) ~ vistype + position_c + (1 | ID)

  • The participant random intercept allows participants to have different typical response speeds. Presentation position adjusts for linear changes in speed across the 21 trials. Model estimates and confidence intervals are converted back from log time to seconds.

    task2 %>%

        position,

  filter(!is.na(time_sec), !is.na(vistype), time_sec > 0)

task2_time_model <- task2_time %>%
  transmute(
    ID = factor(ID),
    vistype = relevel(factor(vistype), ref = "basic"),
    position = as.integer(position),
    time_sec = as.numeric(time_sec)
  ) %>%
  filter(complete.cases(.), time_sec > 0) %>%
  mutate(position_c = position - mean(position))

task2_time_fit <- lmer(
  log(time_sec) ~ vistype + position_c + (1 | ID),
  data = task2_time_model
)

task2_time_estimates <- emmeans(
  task2_time_fit,
  ~ vistype,
  type = "response"
) %>%
  confint() %>%
  as.data.frame() %>%
  transmute(
    vistype,
    estimated_time = response,
    lower_ci = lower.CL,
    upper_ci = upper.CL
  ) %>%
  arrange(estimated_time) %>%
  mutate(vistype = factor(vistype, levels = vistype))

task2_time_estimates |>
  mutate(
    vistype = table_vistype(vistype),
    across(
      c(estimated_time, lower_ci, upper_ci),
      \(x) round(x, 1)
    )
  ) |>
  knitr::kable(
    format = "html",
    col.names = c(
      "Visualization type",
      "Estimated time (seconds)",
      "Lower 95% CI",
      "Upper 95% CI"
    ),
    caption = "Model-estimated detection-task completion time",
    table.attr = kable_table_attributes
  )
