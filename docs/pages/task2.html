Task 2

Task design

Task 2 examined whether participants could combine information about estimated voltage and its uncertainty to locate a relevant spatial region. On each trial, participants saw one EEG topoplot and were asked to select the scalp region with the highest signal-to-noise ratio (SNR), defined as the absolute average-referenced voltage divided by its standard error. They responded using a separate scalp layout divided into 64 selectable regions.

The task included three characteristic ERP patterns: MMN, P3, and N170. Each was shown using each of the seven visualization types. This produced 21 trials per participant, each on a separate page. Trial order was randomized separately for every participant.

Trial reconstruction and scoring

  • For each participant we reconstructed presentation order. Each participant went through 21 randomly shuffled pages.

  • For each trial, survey recorded the visualization, ERP stimulus shown and one region selected by participant. There were 64 regions on selectable grid.

  • The selected region was matched to the corresponding stimulus and its stored region score in regions.txt.

  • The region score is the mean |voltage| / SE in that region, rescaled within each stimulus so that the weakest region scores 0 and the strongest 1. The steps are in the note below.

NoteHow the 0–1 region score was calculated

For each stimulus, the scoring pipeline performed the following steps:

  1. It loaded one average-referenced ERP case using the task, subject, time point, and condition recorded in task_configs_30_balanced. The fixed combinations were:

    ERP pattern Time point (index) Condition
    MMN 96 3
    N170 105 2
    P3 129 1

  2. It average-referenced the voltage across the \(N\) channels:

    \[ V_i^{AR} = V_i - \frac{1}{N}\sum_j V_j. \]

  3. It calculated a polarity-independent, t-like signal-to-noise value at each channel:

    \[ T_i = \frac{|V_i^{AR}|}{SE_i}. \]

  4. It interpolated the channel-level \(T_i\) values into a continuous topoplot grid. Only finite interpolated cells inside the visible head mask were retained.

  5. It fitted the saved 64-region polygon template to the topoplot domain. For each region \(k\), it averaged all retained grid cells that were inside both the polygon and the head mask:

    \[ R_k = \operatorname{mean}\{T(x,y):(x,y)\in\text{region}_k\}. \]

  6. It min–max normalized the 64 raw region scores separately within each stimulus:

    \[ S_k = \frac{R_k - \min_j R_j}{\max_j R_j - \min_j R_j}. \]

    The weakest region therefore receives 0, the strongest receives 1, and other regions are positioned proportionally between them. Scores are rounded to two decimal places.

Detection-score analysis

  • The primary analysis uses the extended model:

    score ~ vistype + pattern + position_c +
  (1 | ID) + (1 | stimulus) + (1 | stimulus:vistype)

  • The outcome contains exact 0 and 1 values as well as intermediate scores. An ordered-beta model retains this graded information while supporting the complete closed interval from 0 to 1. A binary logistic model would instead treat every score below 1 as equally incorrect.

NoteWhat is an ordered-beta model? — Expand

An ordered-beta model (Kubinec, 2023) is a regression model for scores between 0 and 1 that include exact 0s and exact 1s. A plain beta model cannot handle exact 0s and 1s.

It treats each score as one of three ordered outcomes:

Outcome Probability Model part
Exactly 0 P(0) = 1 − logit⁻¹(η − ψ₁) lower cutpoint ψ₁
Between 0 and 1 1 − P(0) − P(1) beta distribution with mean μ = logit⁻¹(η)
Exactly 1 P(1) = logit⁻¹(η − ψ₂) upper cutpoint ψ₂
  • One linear predictor η (visualization, pattern, position and random effects) drives all three parts. A higher η makes an exact 1 more likely, an exact 0 less likely, and the scores in between higher. Each term therefore has a single coefficient: positive means better detection.
  • Coefficients are on the logit scale, as in an ordinal logistic model.
  • Expected score: E[y] = P(1) + (1 − P(0) − P(1)) μ. The back-transformed emmeans value is μ alone, so the expected scores below are computed from all three parts.

Reference: Kubinec, R. (2023). Ordered beta regression: A parsimonious, well-fitting model for continuous data with lower and upper bounds. Political Analysis, 31(4), 519–536. https://doi.org/10.1017/pan.2022.20

  • Every participant completed 21 trials, so responses from the same participant are related. Adding (1 | ID) gives each participant their own baseline detection performance while estimating common visualization, pattern, and presentation-position effects.

  • Some stimuli may be intrinsically easier to interpret than others. Adding (1 | stimulus) gives each stimulus its own baseline score, so visualization comparisons are not attributed to stimulus difficulty alone.

  • Each stimulus was rendered in all seven visualizations, giving 210 distinct images, and each image was seen by about 15 participants. Adding (1 | stimulus:vistype) gives each image its own deviation from what its stimulus and visualization predict. Without it, the responses to one image would count as independent evidence about the visualization, although they share whatever made that particular image easy or hard.

  • ERP pattern and centered presentation position adjust the visualization comparisons for the displayed pattern and for linear change as participants progressed through the task.

  • The simpler base model is shown first as a reference. It contains visualization type and a participant random intercept but does not adjust for pattern, presentation position, or differences among stimuli.

NoteWhy correlated participant-specific visualization slopes were not retained

We tested whether the effect of visualization type differed between participants by adding correlated participant-specific visualization effects: (1 + vistype | ID). The model could not estimate this full structure reliably:

  • It ended with convergence code 1, a non-positive-definite Hessian, and singular convergence.

  • The structure requires seven participant-level random coefficients and 28 variance–covariance parameters.

  • Each participant provided only three detection scores for each visualization type, which did not contain enough information to estimate all those parameters reliably.

We also tested simpler participant-specific structures:

  • A participant-specific position slope, (1 + position_c | ID), converged. Its estimated standard deviation was 0.013 on the logit scale per trial, against a fixed position effect of 0.003. Across the 20 steps from the first to the last trial, one slope SD amounts to 0.26 logit units.

  • A diagonal visualization structure, diag(0 + vistype | ID), which estimates separate participant-specific visualization variances without their correlations, was tried during model building. It is not refitted on this page, so no result from it is reported here.

We therefore retained participant, stimulus and image random intercepts in the primary model. This does not show that visualization effects are identical for every participant. It means that these data cannot reliably estimate the full correlated structure.

Model-estimated detection scores

  • The ordered-beta model has three parts: the probability of an exact 0, the probability of an exact 1, and the mean μ of the continuous scores in between. The back-transformed estimated marginal mean from emmeans(type = "response") is μ only, so it ignores the exact 0s and 1s.

  • The expected score combines all three parts: E[y] = P(1) + (1 − P(0) − P(1)) μ, where P(0) and P(1) follow from the model’s two cutpoints. Because 18% of the responses are exact 1s, E[y] is noticeably higher than μ.

  • E[y] is reported in two forms:

    • Averaged over participants, stimuli and images (primary). The random intercepts are integrated out, so this is the expected score of a new participant on a new stimulus. It is directly comparable with observed means.
    • Typical participant, stimulus and image (random effects set to zero).

# Expected score of the ordered-beta model. glmmTMB stores the two cutpoints
# directly as the "psi" parameters: P(0) = 1 - logit^-1(eta - psi1),
# P(1) = logit^-1(eta - psi2).
task2_expected_score <- function(eta, cut_zero, cut_one) {
  p_zero <- 1 - plogis(eta - cut_zero)
  p_one <- plogis(eta - cut_one)
  p_one + (1 - p_zero - p_one) * plogis(eta)
}

Exact-peak sensitivity analysis

  • About 18% of responses have a score of exactly 1. Scores are rescaled within each stimulus, so a score of 1 marks the strongest region (1 stimulus has two regions tied at 1.00 after rounding to two decimals): these responses are trials in which the participant selected the strongest region. The remaining scores describe how close a miss was.

  • The ordered-beta model handles exact 0 and 1 values, but one linear predictor drives both the probability of a 1 and the location of intermediate scores. A visualization that helps participants find the exact peak without improving near misses (or the reverse) would therefore be averaged into a single effect.

  • Two checks address this:

    1. Posterior predictive check. Data sets are simulated from the fitted ordered-beta model and compared with the observed share of exact-peak responses.
    2. Two-part model. A logistic model for finding the exact peak and a beta model for the scores of the remaining trials, each with the same predictors and random effects as the primary model. Effects in the two parts that differ in direction or strength indicate that the single-predictor ordered-beta contrast summarizes two distinct effects.

Two-part model for hits and misses

  • Exact peak: logistic mixed model for score == 1.
  • Closeness of misses: beta mixed model for the trials with score < 1. The 5 scores of exactly 0 were moved slightly inward with the Smithson–Verkuilen transformation, (score × (n − 1) + 0.5) / n.
  • Both parts use the primary model’s predictors: vistype + pattern + position_c + (1 | ID) + (1 | stimulus) + (1 | stimulus:vistype).
  • The second part is conditional on missing the peak. If a visualization turns near misses into exact hits, its remaining misses can look worse even when overall performance improves, so the two parts should be read together.

Key findings

  • Overall test. Adding visualization type did not clearly improve the primary ordered-beta model, \(\chi^2(6) = 8.68\), p = .192.
  • Expected detection scores (E[y], averaged over participants, stimuli and images). They ranged from 67.8% for Bivariate corner to 72.7% for Adjacent plots; Basic topoplot had 71.2%.
  • Primary contrasts (expected-score difference, Dunnett-adjusted for six comparisons with Basic). No visualization type differed clearly from Basic topoplot: all six intervals included 0. The largest of these was for Bivariate corner (-3.4 pp, simultaneous 95% CI -8.4 to +1.7 pp, adjusted p = .311), but its interval also included 0.
  • Two-part model, overall tests. Visualization type did not clearly improve the exact-peak part (<U+03C7><U+00B2>(6) = 8.4, p = 0.21) and did not clearly improve the part for the closeness of misses (<U+03C7><U+00B2>(6) = 8.7, p = 0.19).
  • Two-part model, exact peak (logistic, Dunnett-adjusted). Relative to Basic topoplot, the log-odds of selecting the strongest region were clearly higher for Adjacent plots (+0.91 logit, Dunnett-adjusted 95% CI +0.05 to +1.76). The intervals for the other five visualization types included 0. The largest of these was for Confidence intervals (+0.69 logit, Dunnett-adjusted 95% CI -0.16 to +1.54), but its interval also included 0.
  • Two-part model, closeness of misses (beta, Dunnett-adjusted). No visualization type differed clearly from Basic topoplot: all six intervals included 0. The largest of these was for Bivariate corner (-0.20 logit, Dunnett-adjusted 95% CI -0.43 to +0.03), but its interval also included 0.
  • Posterior predictive check. The observed share of exact-peak responses lay inside the 95% interval of 1,000 data sets simulated from the primary model for all seven visualization types, and the observed difference from Basic topoplot for five of six. Outside the interval: Bivariate corner difference from Basic (observed +4.2 pp, simulated 95% interval -7.8 to +3.1 pp). The single ordered-beta predictor does not fully reproduce this exact-peak difference, which is why the two-part model is reported.
  • Rank and top-3 outcomes (Dunnett-adjusted). For neither scale-free outcome did any visualization differ from Basic topoplot.
  • Scoring caveat. For 4 of 10 P3 stimuli, the most frequently selected region (R25) ranked only 10th–14th by score. Participants may have targeted the voltage peak rather than the SNR peak; this is not resolved here.
  • Interpretation. Taken together, the data give no clear evidence that any uncertainty visualization changed detection scores compared with Basic topoplot: the overall test gave p = .192, and no Dunnett-adjusted contrast with Basic excluded zero.
