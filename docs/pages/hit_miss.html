Task 2: hit or miss

The Task 2 page scores each response on a continuous 0–1 scale. This page asks a simpler question: did participants click the peak region, a region right next to it, or somewhere else?

Definitions

  • Hit — the selected region is the peak (region score = 1). For one stimulus two regions are tied at 1.00, and either counts.
  • Neighbour hit — the selected region shares a border with the peak region. Regions have 3–8 neighbours (mean 5.2); touching only at a corner does not count.
  • Miss — any other region.
  • A random click would give 1.6% hits and 6.3% neighbour hits.

Where participants clicked

Each topoplot uses the survey’s clickable grid. Region fill shows the ground truth, and dot area shows the share of responses for that region; shares below about 4% get a minimum dot size so that single responses stay visible. Each panel’s subtitle gives its hit rate and n; no panel is singled out as most correct or most missed, because with as few as 7 responses per panel those differences are mostly noise.

Models

Two logistic mixed models with the predictors of the Task 2 models, vistype + pattern + position_c + (1 | ID) + (1 | stimulus) + (1 | stimulus:vistype): one for an exact hit, one for a hit or neighbour hit. The last term gives each of the 210 images (stimulus × visualization) its own intercept, because the ~15 responses to one image are not independent.

Code 
hit_miss_models <- list(
  `Hit` = glmmTMB(
    hit ~ vistype + pattern + position_c +
      (1 | ID) + (1 | stimulus) + (1 | stimulus:vistype),
    family = binomial(link = "logit"), data = hit_miss
  ),
  `Hit or neighbour hit` = glmmTMB(
    close ~ vistype + pattern + position_c +
      (1 | ID) + (1 | stimulus) + (1 | stimulus:vistype),
    family = binomial(link = "logit"), data = hit_miss
  )
)

# Overall test of visualization type: likelihood-ratio test against the same
# model without vistype.
hit_miss_overall <- purrr::imap_dfr(hit_miss_models, \(model, name) {
  reduced <- update(model, . ~ . - vistype)
  chi <- as.numeric(2 * (logLik(model) - logLik(reduced)))
  df <- attr(logLik(model), "df") - attr(logLik(reduced), "df")
  tibble(outcome = name, chi = chi, df = df, p = pchisq(chi, df, lower.tail = FALSE))
})
overall_text <- function(name) {
  r <- hit_miss_overall[hit_miss_overall$outcome == name, ]
  sprintf("χ²(%d) = %.1f, p = %.2f", r$df, r$chi, r$p)
}

hit_miss_estimates <- purrr::imap_dfr(hit_miss_predictions, \(predictions, name) {
  predictions$estimates |>
    transmute(
      outcome = name, vistype, prob = marginal,
      lower = marginal_lower, upper = marginal_upper,
      lower_99 = marginal_lower_99, upper_99 = marginal_upper_99
    )

# Primary family as on the other pages: the six comparisons with Basic,
# Dunnett-adjusted (exact multivariate-t; Monte Carlo, hence the seed).
hit_miss_contrasts <- purrr::imap_dfr(hit_miss_models, \(model, name) {
  set.seed(20261118)
  emmeans(model, ~vistype) |>
    contrast(method = "trt.vs.ctrl", ref = "basic", adjust = "mvt") |>
    summary(infer = TRUE, type = "response") |>
    as.data.frame() |>
    transmute(
      outcome = name,
      vistype = stringr::str_remove(contrast, " / basic$"),
      odds.ratio, lower = asymp.LCL, upper = asymp.UCL, p.value
    )
})

hit_miss_probability_contrasts <- purrr::imap_dfr(
  hit_miss_predictions,
  \(predictions, name) {
    draws <- tidyr::pivot_wider(
      predictions$marginal_draws,
      id_cols = draw, names_from = vistype, values_from = marginal
    )
    # Within each draw, all rates use the same model parameters.
    contrast_draws <- sweep(as.matrix(select(draws, -draw, -basic)), 1, draws$basic, "-")
    types <- colnames(contrast_draws)
    estimates <- setNames(predictions$estimates$marginal, predictions$estimates$vistype)
    difference <- unname(estimates[types] - estimates[["basic"]])

    # As for Task 1, calibrate the interval with the largest absolute
    # standardised deviation across the six comparisons in each draw.
    standard_error <- apply(contrast_draws, 2, sd)
    z_draws <- scale(contrast_draws, scale = standard_error)
    critical <- unname(quantile(apply(abs(z_draws), 1, max), 0.95))
    tibble(
      outcome = name,
      vistype = types,
      difference,
      lower_ci = difference - critical * standard_error,
      upper_ci = difference + critical * standard_error
    )
  }
) |>
  mutate(
    outcome = factor(
      outcome,
      levels = c("Hit", "Hit or neighbour hit"),
      labels = c("Exact hit", "Hit or neighbour hit")
    ),
    vistype = order_vistype(vistype, top_first = TRUE)
  )

Centre bias (exploratory)

This analysis was not planned: it checks whether participants avoided regions at the edge of the head, independent of how strong the signal there was. Border regions are the 22 regions that touch the head outline; rings group the regions by the distance of their centre from the centre of the head.

  • Where the peaks were (descriptive): 26 of the 31 peak regions lie on the border, in 26 of the 30 stimuli. Border regions held 84% of the peaks but received only 36% of the clicks, about their share of the grid (34%); the centre ring, which holds no peak, received 16%.
  • Border regions are chosen less than their score predicts (choice model, exploratory): for regions with the same score, a border region received 0.23 times as many clicks as an interior one (95% CI 0.20–0.28; the interval allows for the overdispersion of the clicks, a factor of 2.6).
  • Every visualization shows it (table below), most strongly Uncertainty markers and least Bivariate corner.
  • Hit rate by peak location (descriptive): 15% when the peak is on the border (26 stimuli) and 40% when it is inside (4 stimuli). With so few inner peaks this difference is not tested.

Interpretation. Two explanations fit these data, and the study cannot separate them. Participants may avoid the edge of the map, as viewers tend to look at the centre of an image. Or, as EEG researchers, they may distrust maxima at the edge of a topoplot, where the values are extrapolated beyond the outermost electrodes. Either way, the centre bias likely explains much of why exact hits were rare, because most peaks were on the border. That the peaks lay mostly on the border is a property of the 30 stimuli and limits how far the hit rates generalize.

Summary of the hit-or-miss results

  • Exact hits are rare for every visualization (15%–21%), but well above chance (1.6%). Adjacent plots has the most exact hits.
  • Counting neighbour hits changes the ranking: Uncertainty markers lands on or next to the peak most often (49%), and Basic topoplot least often (38%).
  • Model-estimated probabilities (averaged over participants, stimuli and images). The probability of a hit ranged from 13% for Basic topoplot to 22% for Adjacent plots (Basic topoplot 13%, 95% CI 8%–20%). The probability of a hit or neighbour hit ranged from 35% for Basic topoplot to 46% for Uncertainty markers (Basic topoplot 35%, 95% CI 26%–46%).
  • Once each image gets its own intercept, the overall effect of visualization type is not statistically significant for either outcome (hit χ²(6) = 8.4, p = 0.21; hit or neighbour hit χ²(6) = 9.3, p = 0.16).
  • Hit vs Basic topoplot (odds ratios, Dunnett-adjusted). Relative to Basic topoplot, the odds of a hit were clearly higher for Adjacent plots (OR = 2.48, simultaneous 95% CI 1.06–5.83, adjusted p = 0.032). The intervals for the other five visualization types included 1. The largest of these was for Confidence intervals (OR = 1.99, simultaneous 95% CI 0.85–4.66, adjusted p = 0.16), but its interval also included 1.
  • Hit or neighbour hit vs Basic topoplot (odds ratios, Dunnett-adjusted). No visualization type differed clearly from Basic topoplot: all six intervals included 1. The largest of these was for Uncertainty markers (OR = 2.23, simultaneous 95% CI 0.88–5.63, adjusted p = 0.12), but its interval also included 1.
  • The stimulus matters more than the visualization: hit rates range from 0% to 70% across the 30 stimuli, against 15%–21% across the seven visualization types.
  • Interpretation. The comparison that excluded 1 (Adjacent plots for hit) comes from an outcome whose overall test was not significant, so it is exploratory and should not be read as evidence that this visualization improved peak detection. The results should be reported as estimates with intervals.
