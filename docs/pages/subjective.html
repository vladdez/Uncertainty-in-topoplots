Subjective evaluation

Rating items

Each participant rated all seven visualizations on four items, each on a 5-point scale. The comparison item was asked right after Task 1; the other three after Task 2, when participants had used each visualization in both tasks. Comparisons within an item are unaffected, but differences between items may partly reflect this timing.

Rating items. A303 measures the likelihood of using a visualization, not its helpfulness. A301 was answered right after the comparison task, before participants had seen Task 2.

NoteLimitation: fixed item order

Within every rating question the visualizations were listed in the same order for every participant: Adjacent plots first and Basic topoplot always last. Order and context effects therefore cannot be separated from differences between visualizations.

Model checks and sensitivity analyses

Code 
# 1. Proportional odds: cumulative-link mixed models with a participant random
#    intercept, with and without visualization-specific thresholds (nominal
#    effects), compared by likelihood-ratio test. clmm2 is used because clmm does
#    not support nominal effects (it ignores the argument with a warning); a
#    fixed-effects clm test would treat each participant's 7 ratings as
#    independent and give too-small p values.
po_tests <- likert_model_data |>
  (\(data) split(data, data$question))() |>
  imap_dfr(function(data_question, question_name) {
    po_fit <- clmm2(
      location = rating_ord ~ vistype, random = ID,
      data = data_question, Hess = TRUE
    )
    npo_fit <- clmm2(
      location = rating_ord ~ 1, nominal = ~ vistype, random = ID,
      data = data_question, Hess = TRUE
    )
    lr_statistic <- 2 * (npo_fit$logLik - po_fit$logLik)
    df <- npo_fit$edf - po_fit$edf
    tibble(
      question = question_name,
      lr_statistic = lr_statistic,
      df = df,
      p_value = pchisq(lr_statistic, df, lower.tail = FALSE)
    )
  })

# 2. Expected ratings (typical participant) vs raw means.
raw_vs_model <- likert |>

# 3. Linear mixed model on the 1–5 ratings: same Dunnett contrasts vs Basic.
likert_lmm_contrasts <- likert_model_data |>
  (\(data) split(data, data$question))() |>
  imap_dfr(function(data_question, question_name) {
    fit <- lmer(rating ~ vistype + (1 | ID), data = data_question)
    question_emmeans <- emmeans(fit, ~ vistype)
    set.seed(20261118)  # adjust = "mvt" integrates numerically (Monte Carlo)
    contrast(
      question_emmeans,
      method = "trt.vs.ctrl",
      ref = which(question_emmeans@levels$vistype == "basic"),
      adjust = "mvt"
    ) |>
      confint() |>
      as.data.frame() |>
      transmute(
        question = question_name,
        vistype = stringr::str_remove(contrast, " - basic$"),
        lmm_difference = estimate,
        lmm_lower = lower.CL,
        lmm_upper = upper.CL
      )
  })

Proportional odds. The likelihood-ratio test rejects proportional odds for 4 of 4 criteria (p from < .001 to .014): the visualizations differ in how ratings are spread over the scale, not only in their location. The analysis therefore reports expected (mean) ratings for a typical participant, which stay close to the raw means (largest absolute difference 0.08 scale points), rather than interpreting the odds ratios.

NoteSeeing the proportional-odds problem — Expand

What the figure shows. Each small panel is one visualization (columns) on one rating question (rows). It compares that visualization with Basic topoplot at four cut-offs of the 1–5 scale: rated at least 2, at least 3, at least 4, and rated 5.

How to read one point. Its height is the odds ratio against Basic: how much more (or less) likely people were to rate the visualization at least this high.

  • 1 (blue dashed line): the same as Basic.
  • 4: four times Basic’s odds; 1/4: a quarter of Basic’s odds.
  • The axis is logarithmic, so “4 times” and “a quarter” are equally far from the line.

How to read the line.

  • Flat: the visualization moves all ratings up or down evenly. One number (an odds ratio) would describe it well. This is what the ordinal model assumes (“proportional odds”).
  • Rising (low on the left, higher on the right): many people gave it a low rating, but some still gave it a high one. Opinions are divided.
  • Falling: almost nobody gave it a low rating, but its lead over Basic shrinks among the top ratings.

What it means here. Several lines are clearly not flat. For example, Bivariate corner and Bivariate range rise steeply for comparison and for appeal: many participants rated them low, yet some still rated them 4 or 5. A single odds ratio would hide this, which is why this page reports mean ratings instead.

Code 
# Odds ratio against Basic at each cut-off, computed from the raw rating shares
# (not from the model); 0.5 is added to counts so that empty cells stay finite.
likert_po_steps <- purrr::map_dfr(2:5, \(cutoff) {
  likert |>
    filter(!is.na(rating)) |>
    group_by(question, vistype) |>
    summarise(share = (sum(rating >= cutoff) + 0.5) / (n() + 1), .groups = "drop") |>
    mutate(cutoff = cutoff)
}) |>
  group_by(question, cutoff) |>
  mutate(odds_ratio = exp(qlogis(share) - qlogis(share[vistype == "basic"]))) |>
  ungroup() |>
  filter(vistype != "basic") |>
  mutate(
    # Columns left to right in the display order (audit V1).
    vistype = order_vistype(vistype),
    vis_label = factor(table_vistype(vistype), levels = table_vistype(levels(vistype)))
  )

ggplot(likert_po_steps, aes(cutoff, odds_ratio, group = vis_label)) +
  geom_hline(yintercept = 1, linetype = "dashed", colour = basic_accent) +
  geom_line(colour = "grey45", linewidth = 0.7) +
  geom_point(size = 2.4, colour = "#222222") +
  scale_x_continuous(breaks = 2:5) +
  scale_y_log10(breaks = 4^(-2:3), labels = c("1/16", "1/4", "1", "4", "16", "64")) +
  facet_grid(
    question ~ vis_label,
    labeller = labeller(question = label_wrap_gen(22), vis_label = label_wrap_gen(12))
  ) +
  labs(x = "Rated at least", y = "Odds ratio vs Basic topoplot (log scale)") +
  # Sizes balanced at the ~1100 px display width like the other rating figures

Computed from the raw rating shares, not from the model; 0.5 is added to each count so that a cut-off nobody reached still gives a finite value.

Random-effects structure. Each participant gave exactly one rating per visualization and criterion. Participant-specific visualization effects ((1 + vistype | ID)) would have one observation per random effect and are not identifiable separately from the observation-level latent error, so the random intercept is the maximal identifiable structure. The linear mixed model below is a sensitivity check that does not rely on proportional odds.

# Sizes of the Likert figures: site version (nominal sizes, drawn at 96/180 of
# nominal by showtext) or print version (true pt; audit V7). Label and point

likert_figure_sizes <- function(print = FALSE) {
  if (print) {
    list(base = print_text$text, title = print_text$text, axis_x = print_text$small,
         labels = print_text$text / ggplot2::.pt, values = print_text$small / ggplot2::.pt,
         caption = print_text$text, point = 1.5, line = 0.4, margin = 4,
         label_space = 84, anchor = print_text$small / ggplot2::.pt, anchor_row = 10)
  } else {
    # Balanced at the ~1100 px display width of the 16-in site figure (audit
    # V2): panel titles one step above the visualization labels, tick numbers
    # and anchors close to the value labels. anchor_row is the height (pt) of
    # the anchor line under each panel.
    list(base = 20, title = 36, axis_x = 28, labels = 34 / ggplot2::.pt,
         values = 30 / ggplot2::.pt, caption = 30, point = 3, line = 0.55,
         margin = 12, label_space = 215, anchor = 26 / ggplot2::.pt, anchor_row = 22)
  }
}

make_likert_estimate_plot <- function(
  question_name,
  show_x = TRUE,
  show_labels = TRUE,
  print = FALSE
) {
  s <- likert_figure_sizes(print)

  plot_data <- likert_estimates |>
    filter(question == question_name) |>
    mutate(
      colour_group = if_else(vistype == "basic", "basic", "other"),
    
      display_label = unname(
        likert_display_labels[as.character(vistype)]
      ),
    
      # Categories on y: top_first puts Basic at the top.
      vistype = order_vistype(vistype, top_first = TRUE)
    )

  p <- ggplot(
    plot_data,
      aes(
    x = estimated_rating,
    y = vistype,
    colour = colour_group
  )
  ) +
    geom_errorbar(
      aes(
        xmin = lower_ci,
        xmax = upper_ci
      ),
      orientation = "y",
      width = 0.12,
      linewidth = s$line
    ) +
    geom_point(size = s$point) +

    # Estimated values
    geom_text(
      aes(label = sprintf("%.1f", estimated_rating)),
      nudge_y = 0.32,
      vjust = 0.5,
      size = s$values
    ) +

    scale_colour_manual(
  values = c(
    basic = basic_accent,
    other = "#222222"
  ),
  guide = "none"
) +

    scale_x_continuous(
      breaks = 1:5,
      labels = function(x) sprintf("%.0f", x),
      expand = expansion(mult = c(0.02, 0.02))
    ) +

    # Hide ordinary y-axis labels
    scale_y_discrete(
      labels = NULL,
      expand = expansion(add = 0.5)
    ) +

    # Show custom labels placed slightly outside the panel
    coord_cartesian(
      xlim = c(1, 5),
      clip = "off"
    ) +

    labs(
      title = unname(likert_panel_titles[question_name]),
      x = NULL,
      y = NULL
    ) +

    plot_theme(base_size = s$base) +

    theme(
      plot.title = element_text(
        hjust = 0.5,
        face = "bold",
        size = s$title
      ),
      axis.text.x = element_text(size = s$axis_x),
      axis.title.x = element_text(size = s$axis_x),
      axis.text.y = element_blank(),
      axis.ticks.y = element_blank(),
      axis.line.y = element_blank(),
      panel.background = element_rect(fill = "white", colour = NA),
      plot.background = element_rect(fill = "white", colour = NA),

      # Space for custom labels
       plot.margin = margin(
    t = 5.5,
    r = 5.5,
        # Small: the anchor line follows directly under the axis.
        b = if (print) 1 else 3,
    l = if (show_labels) s$label_space else s$margin
  )
    )

  if (show_labels) {
    p <- p +
      geom_text(
        data = plot_data,
        aes(
          x = 0.9,
          y = vistype,
          label = display_label,
          colour = colour_group
        ),
        inherit.aes = FALSE,
        hjust = 1,
        size = s$labels,
        lineheight = 1
      )
  }

  if (!show_x) {
    p <- p +
      theme(
        axis.title.x = element_blank(),
        axis.text.x = element_blank(),
        axis.ticks.x = element_blank()
      )
  }

  p
}
