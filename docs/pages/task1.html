Task 1

Task design

Task 1 examined whether adding uncertainty information made the underlying spatial pattern in an EEG topoplot more difficult to recognize. On each trial, participants saw a target ERP pattern and two alternative topoplots. They selected the alternative that most closely matched the target. One alternative represented the same ERP-pattern class as the target, while the other represented a different class.

The task included three characteristic ERP patterns: MMN, P3, and N170. Each was shown using each of the seven visualization types. This produced 21 trials per participant, each on separate page. Trial order was randomized separately for every participant.

Trial reconstruction and order

  • Trial information was reconstructed from the survey records and joined with each participant’s responses using participant, trial, and question identifiers.

Accuracy analysis

  • Every response was coded as correct (1) or incorrect (0).

  • The analysis contains 3,150 responses: 150 participants × 21 trials.

  • Visualization type was treated as a categorical variable, with the basic topoplot as the reference condition.

  • Presentation position was represented by the centered variable position_c, calculated as position - mean(position). Because positions ranged from 1 to 21, their mean was 11. Thus, position_c = 0 represents position 11, negative values represent earlier trials, and positive values represent later trials. This variable tests whether accuracy changed linearly as participants progressed through the task.

  • No responses were excluded for missing values. All 3,150 reconstructed records contained accuracy, visualization type, ERP pattern, presentation position, target stimulus, and distractor stimulus.

Observed accuracy by visualization

  • Accuracy was calculated as correct responses divided by all responses (correct / (correct + incorrect)). Each visualization type had 450 responses (150 participants × 3 trials). This is the raw share of correct answers, not a model estimate.

  • For each visualization type, accuracy was first averaged across three trials within each participant and then summarized across participants.

  • Both views show the across-participant mean and its two-sided 95% t-confidence interval.

Model-estimated accuracy

  • A logistic mixed-effects model estimated the probability of a correct response:

    correct ~ vistype + pattern + position_c +
  (1 | ID) + (1 | stimulus) + (1 | wrong_image)

  • Some participants were generally more accurate than others. Because every participant completed 21 trials, we added a participant random intercept, which allows each participant to have their own baseline accuracy. The model then examines whether accuracy changed with visualization type or trial position across participants.

  • ERP pattern was included as a fixed effect, so visualization comparisons account for systematic accuracy differences among MMN, N170, and P3 trials.

  • Target and distractor stimuli were included as separate random intercepts. This gives each image its own baseline difficulty in each role and prevents unusually easy or difficult images from being mistaken for visualization effects.

  • These probabilities are model-based estimates of average accuracy for each visualisation type. Estimates were calculated for the midpoint of the experiment, weighted equally across the three ERP patterns, and averaged over participant and stimulus differences (random effects).

NoteChoosing how to summarize predicted accuracy

There are three ways to summarize the model:

Option Calculation What it describes
1 Set participant and stimulus differences to zero. Average-baseline participants and stimuli.
2 Average over the participants and stimuli observed in the study, using their fitted random effects. Sample-averaged model prediction.
3 Average over the modelled distributions of participant and stimulus random effects. Population-averaged model prediction.

We chose option 3 because we are more interested in accuracy across the population (Hu et al., 1998; Hedeker et al., 2018).

Accuracy-averaging sensitivity check. We compared Options 2 and 3. Across visualisation types, the largest difference was 0.4 percentage points. This difference did not meaningfully change the relative performance of the visualisation types.

This does not make the sample representative of all EEG researchers.

NoteWhy participant-specific random slopes were not retained

We tested whether the effect of trial position differed between participants by adding a participant-specific position slope: (1 + position_c | ID), while retaining the ERP pattern and stimulus terms. The model produced a singular fit and could not estimate this additional variation:

  • The estimated variance of the position slopes was 0.00046.

  • The estimated correlation between the baseline accuracy and position slopes was -1.00.

Together, these boundary estimates indicate that the data did not contain enough information to estimate participant baseline differences and participant-specific position effects separately.

We also considered participant-specific effects for visualization type. However, each participant provided only three responses for each visualization. Modeling the seven-level visualization factor would require six additional slopes and their covariances, which the available responses could not support reliably.

We therefore retained the simpler random-intercept model. This does not show that the position and visualization effects are identical for every participant. It means only that these data cannot reliably estimate how those effects differ between participants.

Differences vs Basic topoplot

NoteWhat is a contrast? — Expand

A contrast is one comparison computed from a model, for example “Confidence intervals minus Basic topoplot”.

Type What is compared Adjustment Where
Primary (main results) each uncertainty visualization vs Basic topoplot (6 per outcome) Dunnett, for 6 comparisons Task 1, Task 2, Hit or miss, Time, Subjective evaluation
Secondary two uncertainty visualizations against each other (21 pairs) Tukey, for 21 comparisons Task 2, collapsed box
Model coefficients every model term none: for visualization rows, use the primary contrasts coefficient tables

A primary result counts as clear only if it holds after accounting for all six comparisons.

Definitions

  • Adjustment (for multiple comparisons): each extra comparison adds a chance of a false “difference”. An adjustment widens intervals and raises p values so that the whole set of comparisons, not just one, stays at the 95% / 5% level.
  • Dunnett: the adjustment for comparing several conditions with one reference (here, Basic topoplot).
  • Tukey: the adjustment for comparing every condition with every other.
  • Unadjusted p value: the p value of one comparison on its own, ignoring that others were made.
  • Model coefficient: a number in the fitted model; for a visualization it is its difference from Basic topoplot on the model’s scale (here, log odds).

  • These comparisons estimate the population-average accuracy difference between each visualization and the basic topoplot. They are the primary comparisons for Task 1.

  • Multiplicity. The six comparisons with Basic form one family. Their intervals are simultaneous 95% confidence intervals with a Dunnett-type (max-|z|) adjustment: the critical value is the 95th percentile of the largest absolute standardized deviation across the six contrasts in the 10,000 simulated coefficient sets. The adjusted p values use the same distribution. An interval that crosses zero means that the visualization is not clearly different from Basic after this adjustment.

# Dunnett-type simultaneous inference for the six comparisons with Basic:
# standardize each simulated contrast, take the largest absolute value across the
# six contrasts in every draw, and use its 95th percentile as the critical value.
task1_contrast_columns <- setdiff(
  seq_along(task1_vistype_levels),
  task1_basic_reference
)
task1_contrast_sd <- apply(
  task1_contrast_draws[, task1_contrast_columns, drop = FALSE],
  2,
  sd
)
task1_contrast_z_draws <- sweep(
  sweep(
    task1_contrast_draws[, task1_contrast_columns, drop = FALSE],
    2,
    colMeans(task1_contrast_draws[, task1_contrast_columns, drop = FALSE])
  ),
  2,
  task1_contrast_sd,
  FUN = "/"
)
task1_max_abs_z <- apply(abs(task1_contrast_z_draws), 1, max)
task1_dunnett_critical <- unname(quantile(task1_max_abs_z, 0.95))
task1_contrast_z <-
  task1_contrast_estimates[task1_contrast_columns] / task1_contrast_sd

task1_basic_contrasts <- tibble::tibble(
  vistype = factor(
    task1_vistype_levels[task1_contrast_columns],
    levels = task1_vistype_levels
  ),
  difference = task1_contrast_estimates[task1_contrast_columns],
  standard_error = task1_contrast_sd,
  lower_ci = difference - task1_dunnett_critical * standard_error,
  upper_ci = difference + task1_dunnett_critical * standard_error,
  p_adjusted = vapply(
    abs(task1_contrast_z),
    \(z) mean(task1_max_abs_z >= z),
    numeric(1)
  )
) |>
  mutate(
    vistype = factor(vistype, levels = levels(accuracy_estimates$vistype))

# Text helpers: every accuracy sentence on this page is generated from the
# estimates and their intervals. A difference is described as lower or higher
# only when its interval excludes the null value (1 for odds ratios, 0 for
# differences); otherwise the text says that the data cannot distinguish it from
# no difference.
task1_format_p <- function(p) {
  formatted <- format.pval(p, digits = 2, eps = 0.001)
  # A p below .05 that rounds to "0.05" (e.g. .0497) gets four decimals, so the
  # printed value stays on the same side of .05 as the test.
  borderline <- !is.na(p) & p < 0.05 & suppressWarnings(as.numeric(formatted)) >= 0.05
  formatted[borderline] <- sprintf("%.4f", p[borderline])
  if_else(startsWith(formatted, "<"), formatted, paste("=", formatted))
}
task1_number_words <- c("one", "two", "three", "four", "five", "six")

task1_effect_sentence <- function(
  labels, estimate, lower, upper, p,
  scale = c("odds_ratio", "difference"),
  interval_text = "95% CI",
  p_text = "*p*",
  outcome = "the odds of a correct response were"
) {
  scale <- match.arg(scale)
  null_value <- if (scale == "odds_ratio") 1 else 0
  describe <- function(i) {
    if (scale == "odds_ratio") {
      sprintf(
        "%s (OR = %.2f, %s %.2f–%.2f, %s %s)",
        labels[i], estimate[i], interval_text, lower[i], upper[i],
        p_text, task1_format_p(p[i])
      )
    } else {
      sprintf(
        "%s (%+.1f pp, %s %+.1f to %+.1f pp, %s %s)",
        labels[i], 100 * estimate[i], interval_text, 100 * lower[i],
        100 * upper[i], p_text, task1_format_p(p[i])
      )
    }
  }
  lower_set <- which(upper < null_value)
  higher_set <- which(lower > null_value)
  unclear_set <- setdiff(seq_along(estimate), c(lower_set, higher_set))
  sentences <- character()
  if (length(lower_set) > 0) {
    sentences <- c(sentences, paste0(
      "Relative to Basic topoplot, ", outcome, " clearly lower for ",
      knitr::combine_words(describe(lower_set)), "."
    ))
  }
  if (length(higher_set) > 0) {
    sentences <- c(sentences, paste0(
      "Relative to Basic topoplot, ", outcome, " clearly higher for ",
      knitr::combine_words(describe(higher_set)), "."
    ))
  }
  if (length(unclear_set) == length(estimate)) {
    sentences <- c(sentences, paste0(
      "No visualization type differed clearly from Basic topoplot: all ",
      task1_number_words[length(estimate)], " intervals included ",
      null_value, "."
    ))
  } else if (length(unclear_set) > 0) {
    sentences <- c(sentences, paste0(
      "The intervals for the other ", task1_number_words[length(unclear_set)],
      " visualization type", if (length(unclear_set) > 1) "s" else "",
      " included ", null_value, "."
    ))
  }
  # Name the unclear comparisons with the lowest point estimates, so that a
  # suggestive but inconclusive difference is reported with its uncertainty.
  below_null <- unclear_set[estimate[unclear_set] < null_value]
  below_null <- below_null[order(estimate[below_null])]
  below_null <- head(below_null, 2)
  if (length(below_null) > 0) {
    sentences <- c(sentences, paste0(
      "The lowest point estimate", if (length(below_null) > 1) "s were" else " was",
      " for ", knitr::combine_words(describe(below_null)),
      ", but ", if (length(below_null) > 1) "these intervals" else "this interval",
      " also included ", null_value,
      ", so the data are compatible both with no difference and with a ",
      if (scale == "odds_ratio") "moderate reduction in the odds." else
        "moderate accuracy cost."
    ))
  }
  paste(sentences, collapse = " ")
}

NoteWhat is an overall (omnibus) test? — Expand

An overall test, also called an omnibus test, asks one question before any single comparison: does visualization type make any difference at all?

Here it is a likelihood-ratio test that compares two models:

  • a model without visualization type (ERP pattern, position, random effects);
  • the same model with visualization type added.

If adding visualization type makes the model fit clearly better, the visualizations differ somewhere. The result is written as χ²(df) = value, p:

  • df (degrees of freedom) = 6: seven visualizations give six extra parameters beyond the reference, Basic topoplot.
  • χ²: how much the fit improved.
  • p: the chance of an improvement at least this large if visualization type made no difference.
Question Test
Is there any difference among the seven visualizations? Overall test (one test)
Which visualization differs from Basic, and by how much? Six Dunnett-adjusted contrasts (primary)

The overall test cannot say which visualization differs. It pools all six differences into one number, so it can disagree with the contrasts: several small differences can add up to a significant overall test while no single contrast is significant.

Paired-choice sensitivity analysis

Task 1 is a paired-choice experiment: every trial presents one matching and one nonmatching candidate image. We therefore fitted a conditional logistic paired-choice model as a sensitivity analysis. Its candidate-image terms provide a Bradley–Terry representation of each image’s general tendency to be selected. Unlike the primary accuracy model, it assigns each of the 30 candidate images one shared attractiveness parameter regardless of whether that image is matching or nonmatching on a particular trial. It also adjusts for whether an image appeared as the second option.

The data were represented by two rows per trial, with one row for each candidate and one selected candidate within each participant–trial choice set. Visualization effects were estimated as interactions with matching-candidate status because visualization type is constant within a choice set and its main effect therefore cancels. Standard errors were clustered by participant to account for each participant’s 21 choices.

Sensitivity-model details:
  • Model: Conditional logistic paired-choice model with one stratum per participant–trial.
  • Bradley–Terry connection: Candidate-image effects represent each image’s shared tendency to be selected across pairings.
  • Image effects: One shared fixed attractiveness parameter was estimated for each candidate image across matching and nonmatching roles.
  • Adjustment: Matching-candidate effects were adjusted for ERP pattern, presentation position, and whether the candidate was shown second.
  • Repeated choices: Robust standard errors were clustered by participant.
  • Interpretation: An odds ratio below 1 indicates weaker preference for the matching candidate than under Basic topoplot.
  • Multiplicity: Dunnett-adjusted values for the six comparisons with Basic; the joint robust Wald test is reported below.
NoteTerms explanation
  • Conditional: The model compares the two candidate images within the same participant’s trial. It uses the fact that exactly one candidate was selected and removes the separate baseline for each trial. The term does not refer to an experimental condition.
  • Stratum: A stratum is one participant–trial choice set. It contains two rows: one for the matching candidate and one for the nonmatching candidate. The model compares candidates within this set, not candidates from different trials.

Sensitivity-analysis conclusion

After accounting for candidate-image attractiveness, option position, ERP pattern, and presentation position, the joint participant-clustered Wald test indicated that visualization type changed preference for the matching candidate, \(\chi^2(6) = 12.96\), p = 0.044.

Dunnett-adjusted. No visualization type differed clearly from Basic topoplot: all six intervals included 1. The lowest point estimates were for Bivariate range (OR = 0.67, simultaneous 95% CI 0.43<U+2013>1.03, adjusted p = 0.081) and Bivariate corner (OR = 0.71, simultaneous 95% CI 0.45<U+2013>1.12, adjusted p = 0.216), but these intervals also included 1, so the data are compatible both with no difference and with a moderate reduction in the odds.

The sensitivity analysis separates matching performance from images’ general tendency to be selected; it does not replace the primary mixed-effects accuracy analysis.
