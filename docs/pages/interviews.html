Formative interviews

Before the quantitative study, we interviewed 9 people who work with EEG, MEG or clinical EEG. The interviews asked how they use topoplots, what uncertainty means to them, and what keeps them from showing it on topoplots. This page describes the material and the coding scheme. The coded results follow once the coding is done.

NoteStatus (27 Nov 2026)

All nine interviews are coded. Two interviews were coded first as a pilot, and the rules and the codebook were revised before the other seven. The coded units, the figures and the sensitivity analysis follow on this page.

Participants

7 participants are researchers and 2 are clinicians. The clinicians use EEG for diagnosis and reports, not for group statistics. A pilot interview (R0) tested the guide and is not analysed.

Interviews and transcripts

The interviews followed a structured guide of 14 questions and lasted about 15 to 30 minutes. Participants received the main questions in advance. At the start of each interview, they consented to the recording, to the public sharing of an anonymised transcript and to the use of anonymised quotations. The recordings were transcribed with Voice AI (Academic Cloud/GWDG). In the transcripts, names of people, institutions and cities are replaced by black squares (■■■■■); countries are kept.

Coding

The transcripts are coded with one fixed prompt (data/interviews/interview_content_analysis_prompt.md), as for the open-ended feedback in the survey. The main rules:

  • Only the participant’s speech is coded. Each meaning unit expresses one idea and keeps the participant’s wording.
  • Each unit records the guide question it answered, but its code follows its content. A reason for not showing uncertainty, named while answering Q8, is coded under Why it is not shown on topoplots.
  • Prompted marks a unit whose idea the interviewer had named or given as an example before the participant mentioned it.
  • Stance (−2 to +2) is coded only for units that evaluate something: the value of uncertainty on topoplots, or a specific encoding or practice.

Codes by participant

Each row is a code and each column a participant. A dot means that the participant expressed the idea at least once: filled if at least once without a prompt, open if only after the interviewer had named the idea. Researchers and clinicians are shown apart. The number after each code counts the participants who mentioned it. In Why it is not shown on topoplots, a cross marks a reason that the participant explicitly rejected (for example “I don’t think people do it because they want to hide something”); it is not counted.

Proposed encodings and the study designs

The encodings that participants proposed when asked how they would show uncertainty on a topoplot (Q9), grouped by the design of the quantitative study that they resemble. The colour shows the stance where the participant also evaluated the encoding; a small dot marks an encoding proposed without an evaluation.

Code 
interview_design_levels <- c(
  "Adjacent plots", "Confidence intervals", "Bivariate corner and range",
  "Uncertainty markers", "Animation", "Not in the study"
)
interview_stance_colours <- setNames(
  scales::div_gradient_pal("#A6611A", "#F5F5F5", "#018571")(
    scales::rescale(-2:2, from = c(-2, 2))
  ),
  c("−2", "−1", "0", "+1", "+2")
)
interview_encodings <- interview_units |>
  dplyr::filter(Category == "Ideas for showing uncertainty on topoplots", Code != "No idea") |>
  dplyr::left_join(
    dplyr::select(interview_codebook, Code, `Study design`), by = "Code"
  ) |>
  dplyr::group_by(Respondent, Code, `Study design`) |>
  dplyr::summarise(
    # The most negative stance if a participant evaluated it more than once.
    stance = suppressWarnings(min(as.integer(Stance), na.rm = TRUE)),
    .groups = "drop"
  ) |>
  dplyr::mutate(
    stance = dplyr::if_else(is.finite(stance), stance, NA_integer_),
    design = factor(
      dplyr::coalesce(`Study design`, "Not in the study"),
      levels = interview_design_levels
    ),
    stance_label = factor(
      chartr("-", "−", ifelse(stance > 0, paste0("+", stance), as.character(stance))),
      levels = names(interview_stance_colours)
    ),
    Respondent = factor(Respondent, levels = interview_respondent_levels)
  ) |>
  dplyr::left_join(
    dplyr::select(interview_participants, Respondent, Group), by = "Respondent"
  ) |>
  dplyr::mutate(Group = factor(interview_group_levels[Group], levels = interview_group_levels)) |>
  dplyr::add_count(Code, name = "n") |>
  dplyr::mutate(label = paste0(Code, "  ", n))

ggplot(interview_encodings, aes(Respondent, label)) +
  section_bands("design", interview_design_levels) +
  geom_point(
    data = \(d) dplyr::filter(d, is.na(stance)),
    aes(shape = "Proposed, not evaluated"),
    size = 3, colour = "#222222"
  ) +
  geom_point(
    data = \(d) dplyr::filter(d, !is.na(stance)),
    aes(fill = stance_label),
    shape = 21, size = 8, stroke = 0.8, colour = "#222222",
    # Every stance keeps its swatch, also one no participant used.
    show.legend = c(fill = TRUE, shape = FALSE)
  ) +
  scale_fill_manual(
    values = interview_stance_colours, drop = FALSE, name = "Stance",
    limits = rev(names(interview_stance_colours))
  ) +
  scale_shape_manual(values = c(`Proposed, not evaluated` = 16), name = NULL) +
  guides(
    fill = guide_legend(order = 1, override.aes = list(shape = 21, size = 8, colour = "#222222")),

  # Every participant of the group keeps a column, also one who proposed no

  scale_x_discrete(
    position = "top",

        interview_respondent_levels,
        interview_participants$Respondent[interview_participants$Group == group]
      )
    }
  ) +
  facet_grid(
    design ~ Group, scales = "free", space = "free",
    labeller = labeller(design = label_wrap_gen(14))
  ) +
  labs(x = NULL, y = NULL) +
  plot_theme(base_size = 24) +
