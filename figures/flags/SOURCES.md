# Country flags (Country of work charts, pages/sample.qmd)

PNG flags, 160 px wide, from <https://flagcdn.com> (flag images in the public
domain), downloaded 18 November 2026. File names are ISO 3166-1 alpha-2 codes,
mapped from the survey's country names with the `countrycode` R package.
A 3-px grey (60%) border was added to each flag so white areas stay visible on white backgrounds.
